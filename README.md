# Purchase tracker

Organize purchases and wishlist items across Want / Ordered / Delivered.

## Stack

Vite + React 19 + TypeScript. Data persists in `localStorage` under `purchase-tracker.items.v1`.

## Develop

```bash
npm install
npm run dev
```

Dev server: http://127.0.0.1:4317

## Build

```bash
npm run build
npm run preview
```
